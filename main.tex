\title[TEPL]{TEPL: Synthesizing Attribute Builders from Tensor Rewrite Semantics}

\begin{document}
\begin{abstract}
Tensor rewrite rules are concise in algebraic form, but their implementations
require substantial attribute-transformation logic. An algebraic rewrite rule states what to match
and what to build, but not the attribute values the new operators need, such as
permutations and contraction dimensions.
TEPL (Tensor Equality Pattern Language) is a domain-specific language (DSL) for
expressing tensor rewrites with explicit conditions and attribute transformations.
TEPL also synthesizes the axis attributes of the replacement from the semantics of the operations.
We prove that, for a restricted class of tensor rewrites, the synthesis algorithm finds a valid replacement axis assignment whenever one exists.
To support tensors of arbitrary rank, we introduce Axes IR and symbolic axis mapping, which track how axes relate across operations.
For each rule, TEPL compiles a feasibility check and an attribute builder once, so matching does not repeat inference.
We evaluate TEPL on XLA rewrite rules. TEPL
models 123 of 209 concrete rewrite cases. Among the 38 cases requiring axis
inference, it infers and verifies the replacement axes for 31 (81.6\%). For
these 31 cases, inferred specifications use 25.9\% fewer lexical tokens
than specifications with explicit attribute derivations.
\end{abstract}
\keywords{tensor rewrites, attribute synthesis, symbolic axis mapping}
