Original 38-page TEPL draft, saved before the page-limited revision.

This is a standalone project with normal file names and relative paths:
main.tex, sections/, figures/, references.bib, Makefile, and ACM files.
It also includes the outline, storyboards, research notes, and project tools.
Git history (.git/) is deliberately not included.

Build inside this directory:
  make -B

Restore from the parent project directory:
  cp -a main_backup/. .

Or copy all contents of main_backup/ (including hidden files) into the project
folder, allowing existing files to be replaced. main.tex is restored along
with its dependencies. Extra files in the destination are left in place.

The shortened draft stays active at the project root until you restore.
