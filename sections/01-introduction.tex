\section{Introduction}
\label{sec:introduction}
\subsection{Motivation}
Algebraic tensor rewriting is used to optimize tensor computations. A rewrite
rule can be simple in algebraic form, but complex to implement. For example,
consider the dot reassociation rule, $(XY)Z \Rightarrow X(YZ)$. The equation shows how to
rearrange the computation, but general tensor dot operations also need
attributes specifying their batch and contraction dimensions. The rewrite
must compute how these attributes are transformed from the left-hand side (LHS)
to the right-hand side (RHS). For example, in XLA, this single transformation is implemented by the
\code{AssociativeReorderNestedDot} routine in approximately 320 nonblank lines
of C++~\cite{xla-simplifier}, including logic for attribute transformation and
checking applicability. This illustrates the substantial implementation complexity
hidden behind a seemingly simple algebraic rewrite rule.

A key difficulty is that matching the LHS does not determine the
attributes needed on the RHS. Users must therefore write
additional expressions or custom code to compute them. This requires
tracking how axis positions, operand pairings,
and output order change across composed operations. Two axes with the same
size can still represent different coordinates, so sizes alone are not enough
to determine their correspondence. The transformation must also work for
tensors of arbitrary rank; checking a few fixed-rank examples does not
establish that it works in general.

Our research question is: \emph{What if we could design a language that makes
tensor rewriting as easy and intuitive as writing its algebraic form, while
leaving complex attribute transformation to the compiler?}
TEPL pursues this goal by using operation semantics and symbolic axis mapping
to infer replacement attributes under explicit conditions.
Figure~\ref{fig:why-tepl} illustrates the idea with a dot reassociation example.
TEPL lets users write rewrite rules in simple algebraic form and provides tools for
explicitly deriving attribute transformation logic. It also lets the compiler
infer this logic automatically.

\subsection{Central Thesis}
We introduce TEPL, a DSL for practical tensor rewriting that provides
syntactic features for expressing algebraic patterns, applicability
conditions, and attribute transformations together. Our central research
question is how complex, manually written attribute transformation logic
can be delegated to the compiler, and under what conditions the resulting
rewrites can be guaranteed correct.

\subsection{Contributions}
\begin{enumerate}
\item \textbf{A practical language design for tensor rewriting.}
TEPL provides syntactic structures and tools for expressing tensor
rewrite rules concisely and intuitively.
\item \textbf{Automatic attribute inference.}
For supported rewrites, the compiler constructs reusable functions that
compute RHS attributes from source metadata, integrating attribute
synthesis into tensor rewrite rules.
\item \textbf{Symbolic axis mapping for composed operations.}
We propose an algorithm that maps symbolic axis groups across composed
operations using operation semantics, enabling attribute matching for
input tensors of arbitrary rank.
\item \textbf{Correctness and completeness guarantees for a defined fragment.}
For read-once contraction, permutation, and unary summation, with a restricted
additive extension, we prove that our mathematical synthesis algorithm
constructs valid RHS attributes whenever they exist. The constructed
attributes ensure that the replacement is legal and equivalent to the
original computation under the stated assumptions.
\end{enumerate}
Together, these contributions support concise tensor rewrite rules,
automatic attribute synthesis, and formal guarantees for a defined
mathematical fragment. Section~\ref{sec:evaluation} evaluates TEPL on
XLA-derived rewrite cases, examining semantic coverage and the
effectiveness of automatic attribute inference.
