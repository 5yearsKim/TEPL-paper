\section{From Mathematical Synthesis to Symbolic Programs}
\label{sec:method}
The preceding sections define and prove a mathematical synthesis algorithm.
The implementation challenge is to perform this reasoning before concrete
tensor ranks and source attribute values are known.
Following Section~\ref{sec:mathematical-synthesis}, the compiler must
determine which axes each RHS operation retains, their output order,
and their positions in its operands. These decisions must be expressed
symbolically to produce attribute programs that work across different
input ranks and source attribute values.

TEPL addresses this through three mechanisms. Axes IR represents varying
numbers of axes as ordered symbolic groups. Symbolic axis mapping connects
these groups across operations while preserving their positions and pairings.
Attribute program synthesis uses these mappings to generate expressions
that compute replacement attributes from source metadata.
