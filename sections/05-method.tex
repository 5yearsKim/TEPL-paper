\section{Symbolic Axis Mapping and Attribute Programs}
\label{sec:method}
The preceding sections define and prove a mathematical synthesis algorithm.
We now describe TEPL's symbolic machinery: Axes IR represents ordered groups
of arbitrary length, mapping connects coordinates across operations, and
program generation expresses replacement attributes using source metadata.
This machinery is a separate contribution from the completeness theorem.
The general synthesis path also handles cases outside that theorem.

For notation, $\mathsf I_t$ is a symbolic ordered interface, while $P_v$
remains the mathematical live-axis set. Mapping records use position lists
$q$ and a table $\mathcal M$; $p$ remains source metadata. We write
$\iota(G)=\operatorname{range}(|G|)$, reserving $\rho_v$ for declaration
adapters. The reassociation example uses $D$ for the outer contraction group
and $H$ for the final free group, leaving $L,R$ for rewrite expressions and
$F$ for the entire target output order.

We introduce these steps with dot distribution and then follow dot
reassociation through mapping, synthesis, and verification. Distribution
illustrates attribute reuse; reassociation requires constructing new
descriptors for a different intermediate tensor. All algebraic transformations
in these examples require the stated guards and an arithmetic policy that
permits the relevant laws.
