\subsection{Validation Checks}
\label{sec:validation-boundary}
\label{sec:validation-algorithm}
Given a rewrite $L\Rightarrow R$, written condition $C$, feasibility
program $E_q$, and completed attribute program $f$, the validator first
establishes that $E_q$ uses only source metadata and evaluates to a Boolean
on every legal match satisfying $C$. For a sequence of short-circuit
checks, each check is proved defined after its predecessors succeed.
Only then may their truth be used to validate the builder.

Under source legality, $C$, and a true result from $E_q$, validation
establishes three properties:
\begin{enumerate}
\item \emph{Defined attributes.}
The original attribute expressions have valid types, index accesses,
and integer calculations. Supplied fields are preserved, and no holes remain.
\item \emph{Legal replacement.}
The attributes satisfy every RHS operation's axis and extent requirements.
\item \emph{Equivalent result.}
The RHS preserves values and ordered output shape.
\end{enumerate}
Construction relationships other than the validated applicability predicate
remain obligations to prove. For value comparison, TEPL expresses both
graphs as indexed input reads, products, and finite sums, then establishes
equality using checked algebraic laws. It returns \code{Proved} only when
all checks succeed; \code{Unknown} means that correctness remains unproved.
Neither proof search nor attribute synthesis is repeated at match time.

\subsection{Soundness}
\label{sec:acceptance-soundness}
The formal guarantee covers contraction, permutation, unary summation,
and elementwise addition without broadcasting, under exact real arithmetic
and the metadata operations and reasoning rules in
Appendix~\ref{app:validation-proofs}. It allows arbitrary finite ranks and
nonnegative extents.
\begin{theorem}[Conditional validation soundness]
\label{thm:validator-soundness}
If $\operatorname{Validate}(L,R,C,E_q,f,\mathcal G)$ returns \code{Proved}
using these rules, then $E_q$ evaluates to a Boolean for every legal source
match satisfying $C$, and
\begin{equation}
\begin{aligned}
 &\operatorname{Legal}_L(m)\land C(m)
       \land(E_q\Downarrow_m\mathsf{true})\\
 &\qquad\Longrightarrow\exists\beta.\quad f\Downarrow_m\beta
       \land\operatorname{Valid}(m,\beta).
\end{aligned}
 \label{eq:acceptance-soundness}
\end{equation}
Here $m$ is arbitrary legal match metadata, $\mathcal G$ contains candidate
obligations, and $C(m)$ means successful evaluation to true. The notation
$e\Downarrow_m v$ means that $e$ evaluates to $v$ on metadata $m$.
Evaluation abstracts from resource exhaustion; it includes bounds,
types, and integer representability.
\end{theorem}

\begin{proof}[Proof sketch]
Source scope and metadata reasoning establish safe Boolean evaluation of
$E_q$ before its result is assumed. Under a true result and $C$, metadata
reasoning proves attribute definedness and RHS legality. Lowering and
normalization establish value equality; ordered-shape checks complete
validity under the stated dtype-compatibility assumption.
Appendix~\ref{app:validation-proofs} gives the reasoning rules and
soundness argument.
\end{proof}
