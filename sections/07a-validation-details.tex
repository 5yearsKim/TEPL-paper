\subsection{Validation Checks}
\label{sec:validation-boundary}
\label{sec:validation-algorithm}
Given a rewrite $L\Rightarrow R$, guard $C$, and completed attribute
program $f$, the validator establishes three properties:
\begin{enumerate}
\item \emph{Defined attributes.}
The original attribute expressions have valid types, index accesses,
and integer calculations. Supplied fields are preserved, and no holes remain.
\item \emph{Legal replacement.}
The attributes satisfy every RHS operation's axis, extent, and dtype
requirements.
\item \emph{Equivalent result.}
The RHS preserves values, ordered output shape, and result dtype.
\end{enumerate}

The proof uses only source legality and the written guard as assumptions;
relationships proposed during construction must be proved.
For value comparison, TEPL expresses both graphs as indexed input reads,
products, and finite sums, then establishes equality using checked
algebraic laws. It returns \code{Proved} only when all checks succeed;
otherwise, \code{Unknown} means that correctness remains unproved.

\subsection{Soundness}
\label{sec:acceptance-soundness}
The formal guarantee covers contraction, permutation, unary summation,
and elementwise addition without broadcasting, under exact real arithmetic
and Appendix~\ref{app:validation-proofs}'s metadata calculus. It allows
arbitrary finite ranks and nonnegative extents.
\begin{theorem}[Candidate validation soundness]
\label{thm:validator-soundness}
If $\operatorname{Validate}(L,R,C,f,\mathcal G)$ returns \code{Proved}
within this calculus, then
\begin{equation}
 \forall m.\quad \operatorname{Legal}_L(m)\land C(m)
 \Longrightarrow\exists\beta.\quad f\Downarrow_m\beta
 \land\operatorname{Valid}(m,\beta).
 \label{eq:acceptance-soundness}
\end{equation}
Here $\mathcal G$ contains the candidate obligations, and $C(m)$
means successful evaluation to true. The notation $f\Downarrow_m\beta$
means that $f$ evaluates to attributes $\beta$ on metadata $m$.
Evaluation abstracts from resource exhaustion; it includes bounds,
types, and integer representability.
\end{theorem}

\begin{proof}[Proof sketch]
Metadata reasoning proves defined attributes and RHS legality;
lowering and normalization establish value equality. Ordered-shape and
dtype checks complete validity.
Appendix~\ref{app:validation-proofs} gives the full proof.
\end{proof}
