\subsection{Symbolic Mapping Invariants}
\label{app:symbolic-mapping-reassociation}
The mapping state is $\Sigma=(V,\mathcal M,\Pi)$, where
$V[t]=(\operatorname{Ord}_t,e_t)$ stores an ordered interface and a value expression.
A mapping $(\operatorname{Ord}_t,\vec G,p)\in\mathcal M$ satisfies
\begin{equation}
 \gath(\operatorname{Ord}_t,p)=\vec G.
 \label{extended:eq:mapping-invariant}
\end{equation}
Each partition in $\Pi$ lists pairs $(\vec G_i,p_i)$ that cover an
interface exactly once: the concatenated position lists are a permutation
of its positions. Different partitions may group the same interface
differently without changing the tensor. A producer-first traversal
aligns operand interfaces, transports reads through validated mappings,
and composes the declared output axes and value semantics.

\paperparagraph{Reconstruction and composition.}
For a complete binding, concatenate its groups and their position lists.
If $p=p_1\Vert\cdots\Vert p_\ell$ is a permutation, then
\begin{equation}
 Q=\gath(\vec G_1\Vert\cdots\Vert\vec G_\ell,\operatorname{inverse}(p))
 \label{extended:eq:rebuilt-interfaces}
\end{equation}
restores tensor dimension order, including interleaved groups.
Paired overlap matching refines partitions; gather composition
(Equation~\eqref{eq:gather-composition}) derives further selections.
These steps preserve the mapping equations: inverse selection restores
each group's entries at its recorded positions, and paired matching selects
the same entries on both sides. A permutation covers each position once,
so reconstruction also preserves complete partitions.

\paperparagraph{From mappings to attribute builders.}
\label{app:mappings-to-attribute-programs}
For admitted plans, the symbolic adapter interprets the shared metadata IR
of Theorem~\ref{thm:symbolic-compilation} through these mappings. Source-read
correspondence supplies logical axes; restricted additive components are
matched independently. Unresolved reductions or ambiguous read assignments
make lowering unsuccessful, leaving the compiled metadata program available
for native interpretation. Supplied extent and coordinate expressions are
preserved, and completed candidates require independent validation.
Appendix~\ref{app:batched-reassociation-program} gives the complete
reassociation case study.


\paperparagraph{Checked symbolic lowering.}
Lowering translates the shared metadata program into expressions over
captured attributes. Set and list simplifications preserve its computed
results. Lowering may also reorder a contraction group's axes in both
operands by the same permutation. The resulting attribute lists may differ
from the canonical builder's lists, but the paired coordinates, extents,
values, and output order are preserved by reindexing the finite sum.
This semantic preservation is distinct from the exact builder correspondence
proved in Appendix~\ref{app:symbolic-compilation-proof}.
The independent validator checks the completed candidate, including
source scope and definedness of the feasibility checks. Under
the written condition and successful checks, it validates attribute
expressions and rewrite obligations (Theorem~\ref{thm:validator-soundness}).
Other unproved construction goals are never assumptions. Failed lowering
leaves the shared program intact; neither lowering nor conditional
validation is claimed complete.
