\section{Implementation}
\label{sec:implementation-scope}
We implement the TEPL compiler in C++, using an ANTLR-generated
parser~\cite{antlr}. The compiler checks types and attribute records,
infers omitted axis fields, and validates the completed rule.

Compiled rules are stored in an executable representation that can
be exported as JSON. This representation contains the rule's patterns,
conditions, and attribute computations. It separates compilation from
execution: applying a compiled rule requires no parsing, synthesis,
or proof search.

TEPL provides several ways to execute compiled rules. Its built-in
rewrite engine applies rules greedily to graphs defined in TEPL.
For equality saturation~\cite{equality-saturation}, TEPL generates
Rust code from supported executable programs and integrates it with
\emph{egg}~\cite{egg}. Users define dialects and rules in TEPL, and
the generated code and shared runtime provide conditional rewrites
and e-class analysis for shapes and dtypes. This allows users to
express tensor rewrites without manually implementing these
components in Rust.

The XLA prototype connects compiled TEPL rules to existing compiler
passes through a runtime adapter. XLA supplies candidate metadata,
and TEPL checks the rewrite conditions and computes replacement
attributes. XLA retains backend eligibility checks and graph updates.
