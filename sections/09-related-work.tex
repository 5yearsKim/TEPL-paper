\paragraph{Comparison with TensorRight.}
TensorRight verifies tensor graph rewrites for tensors of arbitrary rank and
size. It uses aggregated axes to represent an unbounded number of dimensions
and reduces verification to a finite set of bounded proof obligations checked
by an SMT solver~\cite{tensorright}.
TEPL focuses on automatically constructing the replacement attributes for a
user-specified rewrite. Its Axes IR and symbolic axis mapping track axis order
and position correspondences to synthesize attribute programs, such as
permutations and contraction-dimension lists, from source metadata. TEPL then
checks the completed rewrite using its operation semantics. Arbitrary-rank
verification and axis grouping are established by prior work; this paper's
focus is attribute synthesis for executable tensor rewrites.
