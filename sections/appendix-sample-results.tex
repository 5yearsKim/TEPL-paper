\paragraph{A recorded constructor.}
For \code{transpose_compose}, the recorded compiler output contains
\begin{lstlisting}[language={}]
constructor auto#2:
  permutation = gather(attr_inner.attrs.permutation,
                       attr_outer.attrs.permutation)
declared-conditions: true
additional-guard: true
\end{lstlisting}
The full log also records output-coordinate agreement and successful
compilation and serialized-program validation. The constructor has the
core derivation in Appendix~\ref{app:transpose-validation}; the diagnostic
log is not itself a proof certificate. The dot reassociation row is the
corpus's matrix case with source axis conditions; it does not establish
that the compiler accepted every generalized-dot layout discussed in
Section~\ref{sec:method}.

\paragraph{Verification-only failure and negative control.}
The slice-composition row requests no axis inference. Its supplied start
expression adds the source starts, but the checker cannot establish that
this result fits the attribute's integer type. Thus semantic support and
a plausible attribute formula do not suffice for acceptance. Run A also
records a separate subtraction-to-addition negative control with an
unproved outcome. The control is excluded from all coverage denominators;
its failure is not reported as a formal counterexample result.

\paragraph{Reproduction boundary.}
The import script checks and preserves both the original rule source and
the migrated task for all 123 cases, alongside their recorded hashes and
command outputs. It does not relabel them as a current compiler run.
Run A and run B have compiler SHA-256 prefixes
\code{a647eb68c4de} and \code{96258055f908}, respectively, with recorded
checkout revision \code{a65c09e2a1bb}. Commands containing temporary paths
are historical. Repeating the experiments requires the matching compiler
and source snapshots or a separately reported new run. The per-rule wall
times include command startup and differ from the repeated, phase-level
scalability experiment in Section~\ref{sec:evaluation-cost}.
